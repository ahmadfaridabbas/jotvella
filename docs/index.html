Jotvella — Software Projects / Jotvella
01 / The idea

Structure that recedes while you think.

A familiar hierarchy — notebook, section, page — on a free-canvas model where you can type anywhere.

▤
01

Notebook hierarchy

Notebook → section group → section → page. Nest it as deep as your thinking goes.

◈
02

Type anywhere

Block-based, free-canvas pages. Place text, tables, images, and ink wherever they belong.

✎
03

Rich editor

Rich text, tables, attachments, PencilKit drawings, tags, and wiki-style inter-page links.

⚿
04

Per-section encryption

AES-256 sections unlocked with Touch ID or a passcode. Private stays private.

⌕
05

Fast search

Background full-text indexing with CoreSpotlight. Find a thought the moment you need it.

⇄
06

OneNote import

Reads .one, .onetoc2, and .onepkg via Microsoft's public specs.

02 / Built with

Native, local-first, and calm by default.

A clean-room design made entirely from public Apple frameworks and open specifications.

InterfaceSwiftUI + AppKit
PersistenceSwiftData / Core Data
Document formatFileWrapper package
Drawing / inkPencilKit
EncryptionCryptoKit · AES-256-GCM
AuthenticationLocalAuthentication
Cloud syncCloudKit (iCloud)
Search · OCRCoreSpotlight · Vision
